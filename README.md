# 医療ボランティア推薦 POC

医療機関のプロフィールに合う医療ボランティアを順位づけして推薦し、プランに応じて表示件数（5件／20件／50件）を変える部分だけを作った小さなデモです。人物・施設はすべて架空です。

## このPOCで確かめたこと
- 推薦順位・適合度・「合っている点／足りない点」の理由は、AI（大規模言語モデル）で事前に生成した結果を `data/recommendations.json` に同梱して表示している。実運用ではAPIで都度生成する想定。
- 無料プランは上位5件、有料プランは20件・50件までを表示する。該当者が上限より少ない場合は該当者全員を表示する（テストで確認）。
- 推薦はスコアの高い順で、推薦と除外を合わせると全員が過不足なく含まれる（テストで確認）。
- 職種・地域が募集条件に合わない人は推薦から外し、理由を表示する（テストで確認）。
- 画面は2つの架空の医療機関を切り替えられ、初期表示で無料プランの上位5件が見える。
- 画面: `screens/main.png`（PC幅）、`screens/mobile.png`（スマホ幅）

## 作っていない範囲
- ユーザー登録・ログイン、プロフィール管理
- AIによるプロフィール自動生成、資格・履歴書のAI分析
- 求人掲載、ダイレクトメッセージ、チャットボット
- 会員プラン・月額課金の管理（プランは画面上の切り替えのみ）
- 推薦のリアルタイム生成（同梱した事前生成結果のみ）

## 次の進め方
1. 実際のプロフィール項目と、推薦で重視する条件を確認する。
2. AI API で推薦と理由を都度生成する処理に置き換え、同梱データと同じ形式で返す。
3. ログイン・プロフィール管理・課金とプラン判定を実装し、表示件数の上限をサーバー側で制御する。

## 動かし方
- 画面: `docs/index.html` をブラウザで開く。
- テスト: `npm install` のあと `npm test`
- `data/` のJSONを編集したら `npm run build` で `docs/data.js` を作り直す。
